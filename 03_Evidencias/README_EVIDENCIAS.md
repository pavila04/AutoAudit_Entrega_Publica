# 03 - Evidencias académicas

Las imágenes corresponden a pruebas ejecutadas en Ubuntu y PostgreSQL 18. Se mantienen **los valores de muestra y las capturas originales**, incluidos teléfonos de prueba, para que coincidan con la investigación presentada. No se han reconstruido resultados no verificados.

- `Evidencias_Iniciales/`: pruebas de operaciones DML, reportes, rendimiento y restauración.
- `Evidencias_Recientes/`: configuración, INSERT con ROLLBACK, IP local, seguridad e instalación limpia.
- `seguridad_final_lectura.txt`: diagnóstico previo al ajuste de EXECUTE; leerlo junto con la evidencia posterior del ajuste, no interpretarlo como el estado final de permisos.

Las pruebas de IP muestran `127.0.0.1`, una IP de bucle local, no una conexión remota. La función propietaria de bitácoras sigue teniendo privilegios de modificación. La instalación limpia se verificó en una base independiente.
